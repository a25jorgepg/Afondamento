## Bloque de cita
> Markdown es un lenguaje de marcas ligero con sintaxis de
formato de texto simple, creado en 2004 por John Gruber con
Aaron Swartz.
>
>> Markdown se utiliza a menudo para dar formato a archivos
Léame, para escribir mensajes en foros de discusión en línea
y para crear texto enriquecido utilizando un editor de texto
simple.
