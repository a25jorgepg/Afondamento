# 1. Introducción
La **topología de red** se refiere a la *disposición física y lógica* de los dispositivos en una red. Esta estructura afecta el rendimiento, y la toleracnia a fallos del sistema. :brain:
> "Una buena topología es la base de una red eficiente." - Anónimo
---
# 2. Tipos de Topologías

Las topologías más comunes son:

 1. **Topología de Bus** :bus:
 2. **Topología de Estrella** :star:
 3. **Topología de Anillo** :repeat:
 4. **Topología de Malla** :spider_web:
 5. **Topología de Híbrida** :dna:

Cada una tiene características únicas que la hacen adecuada para distintos escenarios

---

# 3. Comparación de Topologías
| Topología | Cableado | Facilidad de Expansión | Tolerancia a fallos |
| :-------: | :------: | :--------------------: | :-----------------: |
| Bus       | Bajo     | Baja                   | Baja                |
| Estrella  | Medio    | Alta                   | Media               |
| Anillo    | Medio    | Media                  | Baja                |
| Malla     | Alto     | Alta                   | Alta                |
| Híbrida   | Variable | Alta                   | Alta                |

*Fuente: Elaboración propia*

# 4. Ventajas y Desventajas
**Topología en Estrella:**
* Ventajas:
    * :white_check_mark:Fácil de instalar y gestionar 
    * :white_check_mark:Aíslamiento de fallos sencillo
* Desventajas:
   * :x:Dependencia del nodo central
   * :x:Mayor uso de cableado

**Topología en Malla:**
* Ventajas
   * :white_check_mark:Alta redundancia
   * :white_check_mark:Excelente tolerancia a fallos
* Desventajas
   * :x:Costosa
   * :x:Compleja de implementar
